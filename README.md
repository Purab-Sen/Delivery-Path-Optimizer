# Delivery-Path-Optimizer
Optimizing delivery path using KNN and Dijstra's Algorithm
Here, We have taken a location in Andrapradesh, India to apply delivery path optimization for testing the algorithm.

## Datastructure Used:
### i. KDtree
### ii. Stack
### iii. Graph
### iv. ArrayList

## Algorithm Working flow:
### i. KNN algorithm
### ii. Dijstra's Algorithm

## 🚀 Installation & Setup
### 1. Clone the Repository
```bash
git clone https://github.com/Purab-Sen/Delivery-Path-Optimizer.git
```
### 2. Compile and Execute the GUI file
```bash
javac GUI.java
java GUI
```
